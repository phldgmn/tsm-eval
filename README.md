# Theoy of the Smart Machine

## Evaluation using Structural Equation Modeling in R

### Preqrequisite

* R > 4.0.0
* Dependencies:
  * conflicted
  * dplyr
  * tidyverse
  * stringr
  * readr
  * seminr
  * vscDebugger

Install dependencies:

```R
install.packages(c("conflicted", "dplyr", "tidyverse", "stringr", "readr", "seminr", "vscDebugger"))
```
